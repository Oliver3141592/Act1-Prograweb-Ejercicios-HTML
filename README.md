# Actividad 1 - Programación Web

## Descripción
Repositorio con los 18 ejercicios prácticos de la materia de Programación Web, cada ejercicio trabaja un concepto distinto de HTML/CSS/JS (enlaces, imágenes, listas, formularios, etc.), organizados como páginas independientes y enlazadas desde el ['index.html']

## Tecnologías usadas
- Visual Studio Code como editor de texto
- XAMPP como servidor web
- Entorno Java

## Cómo ver la aplicación en el servidor XAMPP
1. Tener instalado el servidor XAMPP y verificar que la opción "Apache" esté encendida.
2. Ubicar en el disco C: la carpeta de instalación de XAMPP, entrar a 'htdocs' y ahí extraer el contenido del archivo .zip del repositorio.
